2. How to Create Virtual Environment

GO to Terminal -> Python -m venv venv
Rule: There should be only 1 virtual environment for one folder


3. Then to Activate the Virtual environment

command -> venv\scripts\Activate

4. Install PyAutoGui

command-> pip install pyautogui

Close the Terminal

5. Create a file basic_pyautogui.py in the folder


Enter the headers

import pyautogui
pyautogui.FAILSAFE = True
pyautogui.pause = 1.0

Go to Terminal

Make sure you are inside the folder in the Terminal path
then Enter 
command -> python basic_pyautogui.py

Mouse 
Keyboard
Switch between windows
Take screenshot
Image recognition
