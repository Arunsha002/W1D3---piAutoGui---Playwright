Topic: Robotic Process Automation (RPA)
- RPA is NOT AI; it existed earlier.
- AI is now used to enhance RPA and make automation smarter.
- Two main tools for RPA:
  1. PyAutoGUI → Desktop automation
  2. Playwright → Web automation

------------------------------------------------------------
PyAutoGUI Basics
------------------------------------------------------------
- PyAutoGUI is a Python package for automating:
  • Mouse actions
  • Keyboard typing
  • Window switching
  • Screenshots
  • Image recognition

------------------------------------------------------------
Setting Up PyAutoGUI
------------------------------------------------------------

1. Create Virtual Environment
   Command:
   python -m venv venv
   Rule: One virtual environment per project folder.

2. Activate Virtual Environment
   Command:
   venv\scripts\Activate

3. Install PyAutoGUI
   Command:
   pip install pyautogui

4. Create Script File
   File name:
   basic_pyautogui.py

   Add these lines:
   import pyautogui
   pyautogui.FAILSAFE = True
   pyautogui.pause = 1.0

5. Run the Script
   Command:
   python basic_pyautogui.py

------------------------------------------------------------
What PyAutoGUI Can Do
------------------------------------------------------------
- Control mouse movements and clicks
- Type text automatically
- Press keyboard shortcuts
- Switch between applications
- Capture screenshots
- Detect images on screen
